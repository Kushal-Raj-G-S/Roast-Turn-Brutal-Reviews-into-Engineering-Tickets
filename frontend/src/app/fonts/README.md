# Premium Font Files Needed

## Download These Fonts:

### 1. **Satoshi** (Ultra-premium sans-serif)
- Download from: https://www.fontshare.com/fonts/satoshi
- File needed: `Satoshi-Variable.woff2`
- Used for: Body text, clean modern feel

### 2. **General Sans** (Geometric perfection)
- Download from: https://www.fontshare.com/fonts/general-sans
- File needed: `GeneralSans-Variable.woff2`
- Used for: Mono-spaced elements, technical text

### 3. **Clash Grotesk** (Editorial display)
- Download from: https://www.fontshare.com/fonts/clash-grotesk
- File needed: `ClashGrotesk-Variable.woff2`
- Used for: Headings, premium feel

## Installation:
1. Download the variable font files (.woff2) from fontshare.com
2. Place them in this `fonts/` directory
3. The layout.tsx is already configured to use them
